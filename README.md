# Gelang Asistif Getar dan Cahaya — aplikasi pendamping

Мобильное приложение-компаньон для ассистивного браслета, который переводит важные звуки
(имя ребёнка, школьный звонок, дверной звонок, сигнал опасности) в вибрацию и цвет светодиода.
Браслет предназначен для глухих детей 7–12 лет (SLB-B и инклюзивные школы Индонезии).

Проект выполняется в рамках курса **Teknologi Asistif**, программа S1 Pendidikan Khusus,
Fakultas Ilmu Pendidikan, Universitas Negeri Surabaya, 2026.

## Как устроена система

| Часть | Что делает |
|---|---|
| Браслет | ESP32 с Bluetooth, монетный вибромотор, один RGB-светодиод, аккумулятор, одна кнопка, силиконовый ремешок. Получает код по Bluetooth, вибрирует по паттерну и зажигает цвет. |
| Приложение | Принадлежит родителю или учителю. Распознаёт звук, шлёт код на браслет, хранит профили детей, настройки, guidebook и режим тренировки. |

Железо в рамках курса не собирается: приложение должно работать как интерактивный мокап,
где подключение браслета и распознавание звука симулируются.

## Коды сигналов

Четыре кода, каждый различим по одной только вибрации (на солнце и для детей с нарушением цветовосприятия).

| Звук | Цвет LED | Вибрация | Чему учим ребёнка |
|---|---|---|---|
| Назвали по имени | синий | 2 короткие | обернуться, найти зовущего |
| Опасность (сирена, клаксон, тревога) | красный, быстро мигает | длинная, повторяется | остановиться, осмотреться, подойти к взрослому |
| Школьный звонок, сигнал времени | жёлтый | 1 средняя | перейти к следующему занятию |
| Домашние звуки (дверной звонок, стук) | зелёный | 3 короткие | сообщить родителям |

## Функции приложения (из книги, таблица 7)

- Вход по email. Один аккаунт, несколько профилей детей и браслетов.
- Профиль ребёнка с одним или несколькими именами, на которые он откликается.
- Подключение браслета, статус на главном экране.
- Настройки звуков: включение категорий и чувствительность. Категория «опасность» не выключается.
- Guidebook: раздел для взрослого (установка, настройка) и для ребёнка (значение кодов, картинки, видео на жестовом языке).
- Режим тренировки: кнопка на каждый код, чтобы ребёнок выучил вибрацию и цвет.
- Ручной вызов: взрослый вызывает ребёнка прямо из приложения, если распознавание не сработало.
- История событий (Riwayat): есть на карточке прототипа, добавляем как лог сработавших сигналов.

Поток экранов: Masuk → Profil anak → Sambungkan gelang → Beranda (статус, вызов) → Pengaturan suara / Guidebook / Mode latihan.
Нижняя навигация с карточки: Beranda, Pengaturan, Riwayat, Bantuan.

Язык интерфейса: индонезийский. Аудитория взрослых не всегда уверенно пользуется техникой, поэтому экраны простые, кнопки крупные, подсказки с картинками.

## Цели

1. Рабочий интерактивный прототип приложения, который можно показать на защите с телефона или ноутбука.
2. Все семь функций из таблицы 7 книги плюс история событий присутствуют и кликабельны.
3. Анимированный браслет на экране: режим тренировки и ручной вызов показывают нужный цвет и паттерн вибрации. На Android дополнительно используется Vibration API, телефон сам играет роль браслета.
4. Симулятор событий: гарантированный путь для демонстрации, работает на любом устройстве без микрофона и сети.
5. Реальное распознавание с микрофона телефона в режиме «Dengar»:
   имя ребёнка через Web Speech API (id-ID), классы звуков (звонок, дверной звонок, стук, сирена, клаксон, тревога) через модель YAMNet в TensorFlow.js, локально на устройстве.
6. Guidebook внутри приложения с картинками кодов и разделом для ребёнка.
7. Публичная ссылка (Firebase Hosting) и при необходимости APK через Capacitor.
8. Материалы для книги: скриншоты экранов и схема «Alur Kerja Produk», которые в PDF пока пустые.
9. Документация: руководство пользователя (ID), памятка для ребёнка и техническое описание для разработчика в `docs/`.

## Не делаем

- Прошивку ESP32 и реальный Bluetooth. Подключение браслета симулируется.
- Собственную модель распознавания. Берём готовую YAMNet и готовый Web Speech API.
- Серверную часть сверх Firebase Auth и Firestore для профилей.

## Известные ограничения режима «Dengar»

- Работает в Chrome на Android, нужен HTTPS. На iPhone Web Speech API ограничен, Vibration API отсутствует, остаётся симулятор.
- Распознавание имени через Web Speech API уходит в облако Google, что расходится с пунктом книги о локальной обработке. YAMNet работает полностью локально. Это ограничение прототипа фиксируем в книге.
- Точность в шумном классе средняя, поэтому есть порог чувствительности и ручной вызов.

## Стек

React 18 + Vite 6 + TypeScript (Vite 6 и React 18 закреплены из-за Node 22.2 на машине разработки).
Деплой: Firebase Hosting. Вход: Firebase Auth по email.

### Порядок внутри режима «Dengar»

1. Запрос доступа к микрофону один раз, статус показан на главной.
2. Один аудиопоток делится между Web Speech API и YAMNet.
3. Событие проходит через настройки: категория включена, уверенность выше порога, с прошлого события той же категории прошло больше 3 секунд.
4. Событие записывается в историю и отправляется «браслету»: анимация на экране плюс Vibration API.
