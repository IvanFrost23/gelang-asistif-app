# Техническая документация (черновик)

Будет заполнено на шаге 12 плана. Разделы:

1. Архитектура и структура папок
2. Домен сигналов: категории, цвета, паттерны вибрации
3. Компонент браслета и Vibration API
4. Симулятор событий
5. Режим Dengar: Web Speech API и YAMNet, маппинг классов, порог, антидребезг
6. Хранение: zustand, localStorage, Firebase
7. Запуск, сборка, деплой
